# Likhith M: Mandya Legend Challenge

A mobile-friendly Streamlit mini-game made for Likhith M from Mandya.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Upload `app.py` and `requirements.txt` to a GitHub repository.
2. Open [share.streamlit.io](https://share.streamlit.io/).
3. Select the repository, branch, and `app.py`.
4. Click **Deploy**.

The friend's name can be changed from the expandable personalization section on the welcome screen.
